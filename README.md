# МДК 05.02 — Разработка кода информационных систем

Учебные материалы и выполненные практические работы по междисциплинарному курсу **«Разработка кода информационных систем»** (профессиональный модуль «Проектирование и разработка информационных систем»): C#, ASP.NET Core, Entity Framework Core, Web API, Identity.

## О курсе

Курс посвящён разработке информационных систем на платформе .NET: от основ языка C# и устройства ASP.NET Core до построения слоистых Web API, работы с данными через Entity Framework Core, аутентификации, интеграции программных модулей и конфигурирования приложения.

**Технологии:** C#, .NET 8, ASP.NET Core MVC, ASP.NET Core Web API, Entity Framework Core, SQLite, Swagger, ASP.NET Core Identity, HttpClient, Polly, Razor.

### Быстрый запуск

```bash
cd practical-works
dotnet restore
dotnet run --project src/RealEstateAgency.Web
```

База SQLite создаётся автоматически. Тестовые аккаунты: `admin@agency.local` / `Admin123!`, `agent@agency.local` / `Agent123!`, `client@agency.local` / `Client123!`.
