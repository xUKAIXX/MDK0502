# МДК 05.02 — Разработка кода информационных систем

Учебные материалы по междисциплинарному курсу **«Разработка кода информационных систем»** (профессиональный модуль «Проектирование и разработка информационных систем»): лекции и практические работы по разработке информационных систем на C# и платформе .NET.

## О курсе

Курс посвящён разработке информационных систем на платформе .NET: от основ языка C# и устройства ASP.NET Core до построения слоистых Web API, работы с данными через Entity Framework Core, аутентификации, интеграции программных модулей и конфигурирования приложения.

**Технологии:** C#, .NET, ASP.NET Core MVC, ASP.NET Core Web API, Entity Framework Core, PostgreSQL, Swagger, ASP.NET Core Identity, JWT, HttpClient, Razor.

## Структура репозитория

.

## Как пользоваться

1. Откройте нужный PDF из таблицы выше.
2. Лекции (`K`) читайте по порядку — они выстроены от основ языка к архитектуре и интеграции.
3. Практические работы (`pr`) выполняйте после соответствующих лекций: в методичках есть цель работы, краткая теория и задания.
