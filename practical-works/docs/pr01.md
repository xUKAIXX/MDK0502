# Практическая работа № 1. Простое веб-приложение ASP.NET Core MVC

**Вариант 3:** агентство недвижимости.

**Тема:** создание простого веб-приложения на ASP.NET Core MVC.

**Цель:** научиться создавать MVC-приложение, описывать модель, контроллер и представления, отображать список объектов и добавлять новые записи через форму.

## Что сделано

Вместо учебного списка книг реализован каталог объектов недвижимости:

- модель `Property` — объект недвижимости: название, адрес, цена, площадь, комнаты, этаж, год постройки, описание, тип, район, агент, статус, владелец;
- контроллер `PropertiesController` — действия `Index` (список) и `Create` (форма и сохранение);
- представления `Views/Properties/Index.cshtml` и `Views/Properties/Create.cshtml`;
- хранение — через репозиторий и EF Core (в исходной методичке — статический список; в итоговом проекте данные сохраняются в SQLite, чтобы приложение работало сразу);
- начальные объекты добавляются сидером `DbSeeder`.

Ключевые файлы:

- `src/RealEstateAgency.Domain/Property.cs`
- `src/RealEstateAgency.Application/Properties/PropertyService.cs`
- `src/RealEstateAgency.Web/Controllers/PropertiesController.cs`
- `src/RealEstateAgency.Web/Views/Properties/Index.cshtml`
- `src/RealEstateAgency.Web/Views/Properties/Create.cshtml`

## Ответы на контрольные вопросы

1. **Компоненты MVC.** Model — данные и бизнес-правила (например, `Property`). View — HTML-представление (Razor-страницы). Controller — принимает запрос, обращается к модели и возвращает представление.
2. **Передача данных из контроллера в представление.** Контроллер возвращает `return View(model)`. В представлении указывается `@model`, и объект доступен через `Model`.
3. **`[ValidateAntiForgeryToken]`.** Атрибут проверяет антифорджери-токен формы. Он защищает от CSRF: злоумышленник не может отправить форму от имени авторизованного пользователя без токена.

## Как проверить

1. Запустите `dotnet run --project src/RealEstateAgency.Web`.
2. Откройте `/Properties/Index` — должен отобразиться список объектов.
3. Нажмите «Добавить объект», заполните форму и сохраните — объект появится в списке.
