# BookList — практические работы № 1 и № 2

Учебное приложение из методичек: простой каталог книг на ASP.NET Core MVC.

## Практическая работа № 1

- Модель `Book` (`Models/Book.cs`);
- контроллер `BooksController` с действиями `Index` и `Create`;
- представления `Views/Books/Index.cshtml` и `Views/Books/Create.cshtml`;
- хранение — статический список в памяти.

## Практическая работа № 2

- `Details` — подробная информация о книге;
- `Edit` — редактирование;
- `Delete` — удаление с подтверждением (GET-подтверждение + POST-удаление);
- поиск по названию и автору;
- сортировка по году издания;
- серверная валидация атрибутами `[Required]`, `[StringLength]`, `[Range]`;
- общее количество книг на странице списка.

## Индивидуальные задания

1. Поле `Genre` с атрибутами `[Required]` и `[Display(Name = "Жанр")]`, фильтрация по жанру.
2. Сортировка по названию и автору с переключением направления при повторном нажатии.
3. Пагинация — по 3 книги на страницу, кнопки «Назад» и «Вперёд».

## Запуск

```bash
cd practical-works/examples/BookList
dotnet run
```

Приложение откроется на `https://localhost:7201`. Список книг — `/Books/Index`.
